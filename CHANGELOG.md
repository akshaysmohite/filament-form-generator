# Changelog

## 0.1.0 — 2026-11-12

Free Filament v3.2+ release.

- Visual canvas for Section, Grid, TextInput, Textarea, Select, Toggle, Checkbox, Radio, and DatePicker
- PHP export as a schema array or a full `form()` method
- JSON import and export, copy to clipboard, and a full-screen workspace
- Page limited to `local` and `testing` unless you change the config
